1. 이 앱은 무엇인가요

「넥스트쿼터」는 유튜브 채널 넥스트쿼터 뮤직(@nextquartermusic)의 운영자가 자기 채널에 뮤직비디오를 올리고 관리하는 데만 쓰는 업로드 도구입니다. 운영자 한 사람만 사용하며, 일반 사용자에게 제공하는 서비스가 아닙니다.

2. 어떤 정보에 접근하나요

운영자가 직접 로그인해 허용한 범위에서 YouTube API 서비스를 통해 다음 작업을 합니다.

  • 운영자 채널에 영상, 썸네일, 자막을 업로드하고 제목·설명·태그를 입력하기
  • 운영자 채널의 재생목록을 만들고 영상을 추가하기
  • 운영자 채널의 영상에 운영자 이름으로 댓글을 작성하기

다른 사람의 계정 정보나 시청 기록, 개인정보는 수집하지 않습니다.

3. 정보는 어디에 저장되나요

로그인으로 받은 인증 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다. 업로드하는 영상과 문구는 운영자가 만든 콘텐츠로, 유튜브에만 전송됩니다.

4. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다.

5. YouTube API 서비스

이 앱은 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

6. 접근 권한 철회

Privacy Policy

Effective date: November 4, 2026

1. What this app is

"Next Quarter" is an upload tool used only by the operator of the YouTube channel Next Quarter Music (@nextquartermusic) to publish and manage music videos on that channel. It is used by the operator alone and is not offered as a service to the public.

2. What it accesses

Within the permissions the operator grants by signing in, the app uses the YouTube API Services to:

  • upload videos, thumbnails and captions to the operator's channel and set titles, descriptions and tags
  • create playlists on the operator's channel and add videos to them
  • post comments on the operator's own videos as the operator

It does not collect account information, watch history or personal data from anyone else.

3. Where data is stored

The sign-in token is stored only on the operator's computer and is never sent to any other server. Uploaded videos and text are the operator's own content and are sent only to YouTube.

4. Sharing

No data is sold or shared with third parties.

5. YouTube API Services

This app uses the YouTube API Services. By using it, you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

6. Revoking access

You can revoke this app's access at any time in your Google Account third-party access settings. Once revoked, the token stored on the operator's computer can no longer be used.
